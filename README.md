# NeuroUnknown findings website

Static site (inline CSS/JS, local assets, no external runtime dependencies). Served by GitHub Pages from the public
`neurounknown` repository; also works opened through any local web server.

## Pages
| File | What it is | Generated by |
|---|---|---|
| `index.html` | App: home (interactive DNA of real catalog genes), brain atlas, disease explorer (cure status, genetics, treatments, overlooked genes), the self in schizophrenia, our screen. Hash routes; phone layout with tab bar and bottom sheets | `src/neurounknown/build_atlas.py` then `build_landing.py` |
| `findings.html` | Full findings: method, filterable candidate table, lead, C11orf87, 3D viewer, biology, gaps, reports; sticky section bar with reading progress | `src/neurounknown/build_website.py` |
| `library.html` | Searchable protein library (100 proteins, papers labelled by evidence type) | `src/neurounknown/build_library.py` |
| `reviews.html` | Rapid reviews A-C and the SCHEMA gene audit | `src/neurounknown/build_reviews.py` |

Old links of the form `index.html#candidates` are redirected to `findings.html#candidates`.
The DNA sequence drawn on the landing helix is decorative (correctly base-paired, not a real gene).
All pages share one design system (`assets/css/site.css`, from `src/neurounknown/site_theme.py`): same header, colours and light/dark theme.
The theme follows the device setting until the visitor picks one; that choice is saved and kept on every page.
Motion respects the reduced-motion setting. A layout switch in the header (auto / phone / desktop) is remembered across pages.

## Regenerate (from `NeuroUnknown/`)
```
PYTHONPATH=src python3 src/neurounknown/build_library.py
PYTHONPATH=src python3 src/neurounknown/build_website.py
python3 src/neurounknown/build_reviews.py
python3 src/neurounknown/build_landing.py
```
Then copy `website/` into the public repository.

Content is computational hypotheses only — no discovery claims.

## 3D brain, gene atlas and daily literature watch (added 22 Nov 2026)

- **3D brain** (`assets/js/brain3d.js`, `assets/brain3d/`): surface meshes built by `src/neurounknown/build_brain3d.py` from the
  MNI152 template and the Harvard-Oxford cortical/subcortical atlases (FSL; free for non-commercial use, MNI template copyright
  McConnell Brain Imaging Centre) and the AAL2 atlas for the cerebellum (GPL). Population-average anatomy, not one person's brain.
  The substantia nigra is not in these atlases; its approximate MNI position is marked with dots. Rendered with three.js 0.160.0
  (MIT, vendored in `assets/js/three/`). Without WebGL the page falls back to the schematic SVG map.
- **Gene atlas** (`assets/data/genome.json`, built by `src/neurounknown/build_genome.py`): 19,203 of 19,299 protein-coding genes at
  GENCODE v43 (GRCh38) positions; 96 have no matching position. Classes are computed (flagged / established / other link / none).
  "When the gene is lost" combines OMIM/Orphanet/ClinGen links, gnomAD v4.1 LOEUF and MGI mouse phenotypes.
- **Diseases**: split into neurological and psychiatric; each statement carries numbered references [n] that jump to a
  reference list with PubMed and DOI links. Guidelines: APA 2020, WFSBP 2012, CANMAT/ISBD 2018, CANMAT 2023, ESCAP 2020,
  European intersocietal AD recommendations 2024, lecanemab appropriate-use recommendations 2023, AAN 2021 (PD), EAN 2024 (ALS).
- **Daily literature watch** (`tools/daily_update.py`, `.github/workflows/daily-update.yml`): every day at 12:00 Europe/Berlin
  (and on demand via "Run workflow"), re-counts PubMed records for flagged and hand-checked genes with the pipeline's query,
  removes a flag automatically when a gene passes 60 records (flags are never added automatically), lists new records for the
  flagged genes and fixed topics, and writes `assets/data/updates.json`. A full rebuild from the private repository overwrites
  `atlas.json`; the next daily run re-applies the counts.

## Version 2.0 (22 Nov 2026)

- **3D atlas v2**: 52 structures (both hemispheres, 102 meshes) from the Neuromorphometrics labels in MNI space (MICCAI 2012
  Grand Challenge data, distributed with SPM12; CC BY-NC). Substantia nigra, subthalamic nucleus, ventral tegmental area and red
  nucleus are approximate ellipsoids (no atlas boundary). 13 textbook systems (limbic, nigrostriatal, basal ganglia loop,
  mesolimbic, default mode, salience, agency, motor, language, memory, executive, visual, auditory). Definitions in
  `src/neurounknown/brain_structures.py`. This replaces the Harvard-Oxford/AAL meshes of version 1.
- **Diseases**: three groups (neurological, psychiatric, neurodevelopmental). Each disease has a guideline-based treatment
  pathway and a synapse diagram with numbered pins for where each drug acts (`src/neurounknown/treatments.py`).
- **Gene atlas**: step-by-step (chromosome cards, then the brain-disease genes on a chromosome, then an optional expert track).
- **News ticker** in the header, fed by `assets/data/updates.json`; the daily job now also scans major journals for our seven
  diseases and counts all new records on them in the last 24 hours.
- **Cite & data** page (`cite.html`) with version number, citation, downloads, sources and how external resources are used.
- **Rollback**: version 1.0 is site commit `f1b6a08` (private repo commit `04b3b30`). Revert with `git revert` to that state.

## Version 2.2 (23 Nov 2026)

  plus 67 hand-written vignettes; distractors whose lesion effects or mechanisms overlap the answer are excluded
  (`clash` map in `quiz.json`). A 3D "spot the lesion" game highlights a random structure on the brain.
- Sections renamed: Our study, 3D Neuroanatomy, Disease atlas, Gene atlas, Test yourself; less-used pages under "More".
- Rollback: version 2.1 is site commit `379ba0a`.

## Version 2.3 (23 Nov 2026)

- One common space for all anatomy: ICBM 2009 nonlinear asymmetric (MNI152NLin2009). Neuromorphometrics and Juelich labels are
  moved into it with 12-parameter affines fitted on brain masks (`src/neurounknown/atlas_affines.json`; Neuromorphometrics
  whole-brain Dice 0.942 -> 0.966, putamen agreement with MASSP 0.69/0.79 -> 0.88/0.85).
- Slices: the same 1 mm slice positions (182 x 218 x 182) as before, but each slice is drawn from the ICBM 2009b template at
  0.5 mm (`assets/brain3d/t1_hd_*.png`, `labels_hd_*.png`, 8 chunks, about 14 MB, loaded after a 1 mm preview).
- 91 structures. New: midbrain, pons, medulla (approximate landmark planes); MASSP 2.0 nuclei (substantia nigra, subthalamic
  nucleus, VTA and red nucleus now real segmentations, plus periaqueductal grey, pedunculopontine nucleus, colliculi, raphe
  nuclei, habenula, geniculate nuclei, claustrum, internal capsule, fornix); Juelich tracts; 12 schematic cranial nerve nuclei.
- Quiz rules: wrong answers never contain or are contained by the right one (e.g. pons vs abducens nucleus), never share a
  lesion-effect family, and imaging-defined networks only take wrong answers from other regions. "Which is NOT involved"
  questions were removed. `tools/site_check.py` runs data, link and browser checks before publishing.
- Feedback bar on every page: opens a prefilled GitHub issue (`.github/ISSUE_TEMPLATE/feedback.yml`).
- Rollback: version 2.2 is site commit `d63d64a`.
