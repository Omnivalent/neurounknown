# NeuroUnknown findings website

Static site (inline CSS/JS, local assets, no external runtime dependencies). Served by GitHub Pages from the public
`neurounknown` repository; also works opened through any local web server.

## Pages
| File | What it is | Generated by |
|---|---|---|
| `index.html` | App: home (interactive DNA of real catalog genes), brain atlas, disease explorer (cure status, genetics, treatments, overlooked genes), the self in schizophrenia, our screen. Hash routes; phone layout with tab bar and bottom sheets | `src/neurounknown/build_atlas.py` then `build_landing.py` |
| `findings.html` | Full findings: method, filterable candidate table, lead, C11orf87, 3D viewer, biology, gaps, reports; sticky section bar with reading progress | `src/neurounknown/build_website.py` |
| `library.html` | Searchable protein library (100 proteins, papers labelled by evidence type) | `src/neurounknown/build_library.py` |
| `reviews.html` | Rapid reviews A-C and the SCHEMA gene audit | `src/neurounknown/build_reviews.py` |

Old links of the form `index.html#candidates` are redirected to `findings.html#candidates`.
The DNA sequence drawn on the landing helix is decorative (correctly base-paired, not a real gene).
All pages share one design system (`assets/css/site.css`, from `src/neurounknown/site_theme.py`): same header, colours and light/dark theme.
The theme follows the device setting until the visitor picks one; that choice is saved and kept on every page.
Motion respects the reduced-motion setting. A layout switch in the header (auto / phone / desktop) is remembered across pages.

## Regenerate (from `NeuroUnknown/`)
```
PYTHONPATH=src python3 src/neurounknown/build_library.py
PYTHONPATH=src python3 src/neurounknown/build_website.py
python3 src/neurounknown/build_reviews.py
python3 src/neurounknown/build_landing.py
```
Then copy `website/` into the public repository.

Content is computational hypotheses only — no discovery claims.
